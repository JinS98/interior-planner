## 결정 사항

1. 좌표의 저장 단위는 미터로 통일. Grid 기본 간격 1m, 초기 Scale 80px/m. 확대할 때 포인터 아래 World 좌표를 고정합니다.
2. 렌더러와 Geometry 함수를 분리. Grid는 CSS 배경이고, 그리는 중인 Vertex/Wall과 완성된 Room 및 오브젝트는 SVG로 렌더링합니다. 100/500/1,000개 물품을 측정해 물품 레이어의 재렌더링과 화면 이동을 최적화했습니다. 측정 조건은 [PERFORMANCE.md](./PERFORMANCE.md)에 기록했습니다.
3. Firestore 영속 데이터와 에디터 임시 상태를 분리. `projectsById`, `floorsById`, `roomsById`, `objectsById`, `paletteItemsById`, `setTemplatesById`로 참조를 정규화합니다.
4. Preview나 Pointer 이동 중 임시 좌표는 저장 스냅샷에 넣지 않고, Pointer 종료 시 한 번의 Command로 확정합니다. Project Store의 변경 전후 데이터로 Undo/Redo를 실행하며 기록은 최근 100개까지 유지합니다.
5. Firebase는 10일차에 연결합니다. 현재는 로컬 프로젝트와 1F를 Store에 생성하고 층 추가·전환·이름 변경·삭제를 로컬 상태에서 처리합니다. UI 저장 버튼은 비활성입니다. 환경 변수, 실제 Firestore 보안 규칙, 오프라인 동기화는 연결 시 확정합니다.

## 데이터 흐름 예정

`Pointer Event → 화면 좌표 → World 좌표 → Geometry 검증 → Command → Project Store → Repository → Firestore`

층별 `roomIds`와 `objectIds`는 Floor에 보관합니다. 새 층에는 활성 층의 Room을 새 ID와 독립된 Vertex 배열로 복제하고, 사용자가 `일반 물품도 함께 복제`를 선택했을 때만 일반 Object를 새 ID로 복제합니다. 각 층은 나란히 표시하며 활성 층만 편집하고 다른 층은 도면 전체를 맞춘 읽기 전용 미리보기입니다. 도면 숨기기·크게 보기와 탭 선택은 화면 표시 상태만 바꾸며 저장 대상 Floor 데이터에는 영향을 주지 않습니다. 반투명 겹쳐 보기도 FloorBoard의 화면 상태로만 관리합니다. 선택한 비교 층의 Room과 Object를 활성 층의 Viewport로 변환해 같은 SVG에 옅은 색으로 그리며, 비교 층 도형은 포인터 이벤트와 선택·편집 대상에서 제외합니다. 층 전환은 Editor Store의 활성 Floor ID만 바꾸고 선택·그리기 초안·편집 미리보기를 지웁니다. 전환하거나 표시 칸의 수를 바꾸면 활성 편집 영역의 크기를 측정해 공간과 회전된 물품의 World 경계를 중앙에 맞추고, 화면에 들어오도록 배율을 조정합니다. 층 생성·이름 변경·삭제는 Project Store에서 Command로 기록하며, 층 삭제 시 그 층의 Room과 Object도 함께 제거하고 Undo로 복원할 수 있습니다. Viewport는 층간에 공유합니다.

층 연결 물품은 Palette의 `floorConnector` 속성으로 구분하며, 물품 추가 양식과 선택한 Palette 항목의 토글에서 변경합니다. 설정 변경은 이후 배치에 적용하고 기존 Object의 연결 여부는 유지합니다. 배치하면 프로젝트의 모든 층에 같은 좌표와 외형의 Object를 하나씩 만들고, `floorConnectionId`로 묶습니다. 각 Object의 `fromFloorId`와 `toFloorId`는 프로젝트 층 순서상 바로 아래·위 층을 가리키며 끝층에서는 `null`입니다. 층을 추가할 때 일반 물품 복제 여부와 관계없이 연결 물품을 새 층에도 만들고, 층을 삭제하면 남은 물품의 연결 ID를 갱신합니다. 연결 물품의 이동·외형 변경·잠금·삭제·붙여넣기는 같은 연결의 모든 층에 한 Command로 반영합니다. 도면에는 위층과 아래층 이름을 표시해 연결 위치를 확인할 수 있습니다.

배열 배치는 Editor의 임시 개수·간격 설정으로 중심 좌표 목록을 만든 뒤 Project Store의 단일 Command로 확정합니다. 층 연결 물품은 배열의 각 칸마다 별도 `floorConnectionId`를 만들고 모든 층에 복제합니다. 공간 경계 Snap은 물품 또는 배열 전체의 외곽 크기를 기준으로 벽의 안쪽 법선 방향에 중심을 맞추고, 모서리에서는 벽 구간 안에 들어오도록 위치를 제한합니다. 물품 회전과 공간 회전은 드래그 각도가 90° 배수에서 8° 이내일 때 정확한 직각으로 보정합니다. 공간은 별도 회전 값을 저장하지 않고 꼭짓점 좌표를 중심 기준으로 변환해 기존 Polygon 유효성 검사를 거쳐 저장합니다.

Pan/Zoom은 `Pointer Event → Editor Store(Viewport) → 렌더링`으로 끝나며 Firestore에 저장하지 않습니다.

공간 그리기 중인 Vertex는 Editor Store의 임시 상태에 두고, Room을 닫을 때 Project Store에 확정합니다.

Palette의 기본 항목은 책상·의자이며, 사용자가 추가한 물품의 이름·종류·기본 외형은 Project Store의 `paletteItemsById`와 프로젝트의 `paletteItemIds`에 둡니다. 선택한 항목과 배치 중 외형은 Editor Store에 두고, 미리보기는 화면에서 계산합니다. 클릭할 때 선택한 항목의 중심을 World 좌표에 맞춰 Project Store의 `objectsById`와 해당 층의 `objectIds`에 한 번 추가합니다. 배치된 오브젝트는 물품의 이름·종류·외형을 복사해 보관합니다.

가구 스냅은 현재 층의 기존 오브젝트 중심을 기준으로 가로·세로 정렬을 계산합니다. 두 오브젝트의 중심 높이가 같고 서로 떨어져 있으면 양쪽 바깥으로 같은 빈 간격이 되는 후보를 추가합니다. 화면 픽셀 기준 허용 거리로 판정하고, 미리보기와 클릭 확정에 같은 함수를 사용합니다.

각 가구는 프리셋의 기본 크기·색상·모양을 갖지만, 배치 설정으로 덮어쓸 수 있습니다. 확정한 오브젝트의 가로·세로 크기, 색상, 모양은 Project Store에 저장합니다. 선택·크기 조절 중 미리보기는 Editor Store에 두고 손잡이를 놓을 때 한 번 확정합니다. 도면 안 텍스트는 사용하지 않고 색상과 모양으로 구분하며, 이름은 Palette와 속성 패널에 표시합니다.

물품 이동은 드래그 시작 시 Viewport를 보관하고, 화면 이동량(px)을 그 배율(px/m)로 나눠 World 이동량(m)으로 바꿉니다. 이동 중에는 Editor Store에서 미리 보이며 Pointer 종료 시 X·Y 미터 좌표만 Project Store에 기록합니다. 화면 Pan 오프셋은 이동량 계산에 영향을 주지 않습니다.

선택 도구의 `Shift+클릭`은 물품 선택을 추가하거나 해제합니다. 빈 도면 드래그는 새 영역 선택, 방 위의 `Shift+드래그`는 기존 선택에 추가하는 영역 선택입니다. 영역과 회전된 물품의 Bounding Box가 닿으면 선택합니다. 다중 이동에서는 선택한 모든 물품에 동일한 World 이동량을 적용하고, 격자 교차선 또는 선택되지 않은 물품의 중심과 가까운 축을 보정합니다. 이동 미리보기와 기준선은 Editor Store에 두고, 놓을 때 Project Store에서 한 번에 좌표를 갱신합니다.

물품 복사본은 Editor Store의 실행 중 클립보드에 속성 스냅샷으로 보관합니다. 붙여넣기는 새 ID와 0.25m씩 늘어나는 이동량을 적용해 Project Store에 한 번에 추가하고 새 물품을 선택합니다. 잠금은 Project Store의 `LayoutObject.locked`에 기록하며, 변경·이동·삭제 액션에서도 잠금을 검사합니다. 여러 물품을 삭제할 때 잠긴 물품은 남깁니다. 잠긴 물품의 복사본은 새로 편집할 수 있도록 잠금 해제 상태로 생성합니다.

### 7일차: 사용자 세트와 거리 측정

사용자 Palette는 책상·의자를 기본으로 시작하며 PC·모니터·POS·카운터 같은 물품은 필요할 때 직접 등록합니다. `SetBuilder` 작업판은 등록 물품을 배치하고 좌표·크기·회전·모양·색상을 수정해 세트를 만듭니다. `normalizeSetMembers`는 회전된 외곽을 포함해 중심을 구한 뒤 각 물품을 중심 기준 상대 좌표로 복사합니다. 이름과 물품이 있어야 완료할 수 있습니다. 완성된 `ObjectSetTemplate`은 프로젝트의 `setTemplateIds`와 `setTemplatesById`에 저장하고, Palette 원본 변경과 독립적으로 재사용합니다. 제작 중 물품과 선택·Undo/Redo는 `SetBuilder`의 임시 상태이며, 배치·삭제·복제·속성 변경은 기록하고 드래그는 놓을 때 한 번 기록합니다. 세트를 완료하면 템플릿 생성이 Project Store의 한 Command가 됩니다.

세트 배치는 `objectSetFootprint`와 배열 개수·간격으로 중심 좌표를 계산합니다. `snapObjectPlacement`를 세트 작업판과 도면 배치에 같이 사용해 가로·세로 정렬, 같은 간격, 아랫줄 시작선 보정 결과를 미리보기와 확정 좌표에 일치시킵니다. `createObjectSetArray`는 각 배열 칸의 물품에 별도 `groupId`를 부여하고 한 Command로 저장합니다. 물품에는 원본 템플릿을 가리키는 `groupTemplateId`도 남깁니다. 템플릿 수정은 이미 배치된 물품의 외형을 자동 변경하지 않습니다.

보통 선택에서는 같은 `groupId`의 물품 전체를 선택합니다. 선택된 물품을 함께 이동하고 그룹 중심 주위로 각 물품의 중심과 회전 각도를 바꿉니다. 회전 손잡이의 직각 보정과 90° 버튼을 제공하며, 드래그 미리보기는 Editor Store에 두고 놓을 때 Project Store에 한 Command로 확정합니다. 그룹 복제·붙여넣기와 층 복사는 새 `groupId`를 만들어 원본 그룹과 독립시킵니다. 내부 편집 모드에서는 한 구성 물품만 선택해 기존 물품 편집 기능을 적용하고, 변경은 현재 배치된 그룹에만 남깁니다. 내부 편집에서 물품 하나를 복사하면 그룹 관계를 제외한 개별 물품으로 복사합니다. 그룹 선택·내부 편집 모드는 `editorStore`의 임시 상태입니다.

Alt를 누른 채 다른 공간 또는 물품 위에 포인터를 올리면 `src/features/editor/measurement.ts`가 회전된 외곽을 포함한 두 요소의 최소 거리를 World 미터 단위로 계산합니다. 거리선·값·대상 윤곽은 `EditorCanvas`의 임시 SVG 가이드이며 프로젝트 데이터와 Command에 포함하지 않습니다.

### 8일차: 자동 배치 기하 계산

`src/features/autoPlacement/geometry.ts`는 유효한 Room Polygon에서 축 정렬 외곽과 각 벽의 접선·안쪽 법선을 계산합니다. Shoelace 부호를 사용하므로 꼭짓점이 어느 방향으로 나열되어도 안쪽 법선이 일정합니다. 오브젝트 세트의 상대 좌표와 구성 물품별 기존 회전을 유지하면서 세트 전체를 0°·90°·180°·270° 및 Room 벽과 평행·수직인 각도로 회전시키고, 중복 각도를 제거합니다. 각 후보는 중심 기준 구성 물품의 회전된 외곽을 가지며, 이를 지정한 중심에 옮겨 Room 내부 포함 여부를 판정합니다. 사각형 외곽을 사용하므로 원·삼각형 물품은 보수적으로 취급합니다. 오목한 Room에서 구성 물품의 꼭짓점뿐 아니라 변이 경계를 벗어나는 경우도 제외합니다.

`src/features/autoPlacement/gridCandidates.ts`는 화면 배율과 무관한 World 원점 기준 격자를 순회합니다. 각 중심·회전 후보에 대해 Room 포함, 선택적 벽 여유, 같은 층의 기존 물품과 회전된 직사각형 외곽 충돌, 지정한 최소 통로 폭을 검사합니다. 접촉은 통로 폭이 0일 때 허용하고 실제 겹침은 분리축 판정으로 제외합니다. 통로 폭은 새 후보와 기존 물품 사이의 최소 거리이며, 벽 여유는 별도 옵션입니다. `selectCompatibleCandidates`는 후보들을 순서대로 선택하면서 새로 고른 후보끼리도 같은 간격을 지킵니다. 과밀 격자는 오류를 반환하고 결과 개수는 상한과 `truncated` 상태로 제한합니다. 이 최소 간격 검사는 전체 공간에 연속된 보행 경로가 존재함을 보증하지 않습니다.

격자가 촘촘해 후보 상한에 도달할 때는 방의 위쪽부터 후보를 채우지 않고, 2의 거듭제곱 간격으로 방 전체를 먼저 탐색한 뒤 누락된 격자점을 점차 채웁니다. `truncated`는 세밀한 후보 일부가 상한 때문에 제외됐음을 뜻합니다. 격자 간격은 후보 위치의 탐색 해상도이며 물품 사이의 실제 최소 거리는 별도의 통로 폭 설정입니다.

`AutoPlacementPanel`은 물품 도구에서 선택한 단일 Palette 물품 또는 사용자 세트와 배치할 Room을 입력받습니다. Palette 물품은 현재 배치 외형으로 한 구성원짜리 임시 템플릿을 만들어 같은 후보 계산을 거치며, 적용 결과는 그룹이 없는 일반 물품입니다. 층 연결 Palette 물품은 수동 배치와 같이 모든 층의 같은 좌표에 생성합니다. 세트는 구성 물품별 위치·회전과 그룹 관계를 유지합니다. 격자 간격 0은 무한한 후보가 아니라 Room 외곽의 긴 변을 최대 약 80칸으로 나누되 최소 0.1m로 올림한 자동 해상도입니다. 배치 후보는 `App`의 임시 상태에만 있고 `EditorCanvas`에서 반투명 물품으로 표시합니다. 취소·층 전환·도면 편집·배치 대상 변경은 미리보기를 지웁니다. 적용은 Project Store가 현재 Room·물품으로 계획을 다시 계산해 미리보기와 일치하는지 확인한 뒤 한 Command로 확정합니다. 적용 뒤에는 Undo/Redo로 전체 배치를 함께 되돌리고 다시 실행할 수 있습니다. 층 연결 물품의 자동 배치 충돌 검사는 선택한 층을 기준으로 하며 다른 층의 물품과 공간은 별도 검사하지 않습니다.

탐색 격자 입력 옆의 `?` 버튼은 네이티브 `dialog` 모달을 열어 0·0.1·0.5·1m의 의미와 물품 간격·벽 여유의 차이를 설명합니다. 설명을 사이드바에 상시 펼치지 않으며 키보드 Escape 또는 닫기 버튼으로 모달을 닫을 수 있습니다.

`src/features/history/command.ts`의 Command는 정규화된 프로젝트 데이터의 변경 전후 상태를 보관합니다. Project Store 액션이 실제로 데이터를 바꿀 때 한 Command를 추가하고 Redo 기록을 비웁니다. 드래그 중 미리보기, 선택, Viewport, 복사 클립보드는 Command에 포함하지 않습니다. 되돌리기와 다시 실행 뒤에는 존재하지 않는 선택 항목을 해제합니다. 목표 면적과 물품 색상 입력은 확정 시 한 번 Store에 전달합니다. 기록은 실행 중에만 유지하고 프로젝트 데이터를 새로 불러오면 초기화합니다.

키 조합은 `src/features/editor/shortcuts.ts`에서 편집 동작으로 해석하고 Canvas가 현재 도구·선택·제스처 상태에 따라 실행합니다. 도구 버튼에 표시하는 알파벳도 같은 매핑을 사용합니다. 입력 필드·IME 조합 중에는 편집기 단축키를 실행하지 않고, 버튼·링크에 포커스가 있으면 Space의 기본 활성화 동작을 유지합니다. 드래그 중에는 `Esc`가 미리보기를 취소하며 Undo/Redo와 도구 전환은 드래그 종료 후 사용합니다.

완성된 Room의 Vertex를 드래그할 때도 Editor Store의 미리보기 좌표로 면적과 차이를 갱신합니다. 교차·겹침·짧은 벽·면적 0 검사를 통과한 좌표만 Pointer 종료 시 Project Store에 기록합니다. 벽 길이 입력은 벽의 시작점을 고정하고 끝점을 원래 방향으로 이동시킵니다.

선택 도구에서 Room 내부를 드래그하면 화면 이동량을 현재 Scale로 나누어 모든 Vertex에 같은 World 이동량을 적용합니다. 미리보기는 Editor Store에 두고 Pointer 종료 시 Project Store에 확정합니다. 꼭짓점과 벽 선택은 내부 드래그보다 우선합니다.

분할 도구는 같은 Room 경계 위 시작점과 끝점 사이에 내부 꺾임점을 0개 이상 추가해 벽 경로를 만듭니다. 각 선분이 Room 내부를 지나고 결과 Polygon 두 개가 유효하며 면적 합계가 원래 면적과 일치할 때만 Project Store에서 한 Room을 두 Room으로 갱신합니다. 기존 Room ID는 한쪽에 남기고 새 ID를 다른 쪽에 부여하므로 공간 개수가 하나 늘어납니다. 현재는 각 Room이 독립적인 Vertex 배열을 가지며, 분할 뒤 공유 벽을 편집할 때 인접 Room 좌표를 함께 바꾸는 기능은 아직 없습니다.

공간 그리기와 분할 중 `Esc`는 Editor Store의 임시 점 배열에서 마지막 클릭 한 개만 제거합니다. 분할 경로의 첫 점까지 제거하면 분할 임시 상태가 비워집니다.

새 Vertex의 미리보기와 확정 좌표에는 같은 Snap 판정을 적용합니다. 시작점 닫기를 우선하고, 격자와 직전 Vertex 기준 수평·수직 후보가 겹치면 두 기준에 모두 맞거나 화면에서 더 가까운 후보를 선택합니다.

## 범위 경계

현재 구현에는 다층 연결과 사용자 세트·그룹 편집, 자동 배치 미리보기와 1,000개 물품 렌더링 측정이 포함됩니다. 3D 미리보기·Firebase 저장·첫 배포는 로드맵의 남은 작업입니다. 전문 CAD·BIM·건축 구조 계산은 대상이 아닙니다.
